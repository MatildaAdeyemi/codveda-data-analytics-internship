Codveda Data Analytics Internship
This repository contains projects completed during the Codveda Data Analytics Internship.

Level 1: Data Cleaning and Exploratory Data Analysis
Task 1: Data Cleaning and Preprocessing
Loaded datasets using Pandas
Checked for missing values
Removed duplicate records
Standardized data formats
Task 2: Exploratory Data Analysis (EDA)
Calculated summary statistics
Created histograms and boxplots
Performed correlation analysis
Visualized customer churn patterns


Level 2: Machine Learning
Task 1: Regression Analysis
Built a Linear Regression model using stock price data
Split data into training and testing sets
Evaluated model performance using R² Score and Mean Squared Error
Task 3: K-Means Clustering
Standardized the Iris dataset using StandardScaler
Applied K-Means clustering
Used the Elbow Method to determine the optimal number of clusters
Visualized clusters using scatter plots

Level 3: Predictive Modeling and Dashboard Development
Task 1: Predictive Modeling (Classification)
Built Logistic Regression, Decision Tree, and Random Forest models
Evaluated models using Accuracy, Precision, Recall, and F1 Score
Performed Hyperparameter Tuning using Grid Search
Selected Random Forest as the best-performing model
Task 2: Power BI Dashboard
Created KPI cards and interactive visualizations
Analyzed customer churn patterns
Added slicers and filters for interactive exploration
Developed a customer churn dashboard using Power BI
